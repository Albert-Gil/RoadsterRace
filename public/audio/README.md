# Optional game recordings

Place approved short audio files here, then assign their roles in `src/presentation/audio-assets.ts`. Empty roles use original synthesized audio. See `docs/SOUND_GUIDE.md` for briefs, loop conventions, limits, mix settings and verification.

The 21 MP3s in this folder are optimized copies of user-supplied WAVs from `audio_files.zip`, `Electric_motor.wav` and `menu_background.wav`. Original masters are preserved locally outside the public runtime folder. See `docs/AUDIO_INTEGRATION.md` for mapping, preparation, source information and the menu-music brief. The 64-second music track streams separately from short sound effects.

No service credentials belong here. Only files intentionally included in the game belong in this public folder.
